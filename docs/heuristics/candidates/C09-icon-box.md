# C09 — Rounded icon boxes

**Reported tell:** "icon boxes with rounded corners" (S1c).

**Proposed mechanism (hypothesis):** The standard generated feature card puts a single icon in a tinted rounded square above the title.

**Measurement:** Count of small square-ish elements (28-72px) with a rounded corner and a filled background that contain a single icon or emoji and no other text.

**Known failure modes:** App UIs with avatar or icon buttons; human-built SaaS sites that use the same pattern.

**Open questions:** Count versus appearing in a repeated group (see C10).
