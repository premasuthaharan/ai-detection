# C21 — Faint monospaced descriptors

**Reported tell:** "very faint monospaced font for descriptors" (S1c).

**Proposed mechanism (hypothesis):** Newer generator output uses small low-contrast monospace labels as a technical-looking accent.

**Measurement:** Count of short text elements outside code blocks set in a monospace family with low contrast against their background.

**Known failure modes:** Developer tools and documentation sites.

**Open questions:** Contrast cutoff.
