# C19 — Testimonial card grid

**Reported tell:** "testimonial grids" (S2).

**Proposed mechanism (hypothesis):** The templated page ends with a grid of quote cards with avatars.

**Measurement:** Largest group of sibling cards that each contain a longer quote paragraph and a small round avatar. Extends the shipping `testimonialAvatars` signal, which only looks for a row of small circles.

**Known failure modes:** Human sites with real testimonials use the same layout.

**Open questions:** Whether it adds beyond the avatar signal.
