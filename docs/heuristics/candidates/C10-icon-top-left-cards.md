# C10 — Teaser cards with icon at top left

**Reported tell:** "Teaser boxes with icon top left" (S1b).

**Proposed mechanism (hypothesis):** Generated feature grids place the icon at the card's top-left corner above the heading.

**Measurement:** Largest group of three or more sibling cards where each contains an icon near the card's top-left corner with the heading below it. Refines the shipping `layout` signal, which does not check icon position.

**Known failure modes:** Any feature grid, including human-designed ones.

**Open questions:** Whether position adds anything beyond the existing `layout` signal.
